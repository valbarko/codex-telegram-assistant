# Уведомления об оплатах проектов

Помощник раз в минуту читает подтверждённые счета четырёх продуктов: «Тренер в
кармане», «Где мои клиенты», «Где мои ученики» и «Тело в порядке». В ТВК входят
подписки и индивидуальные программы; в «Теле в порядке» также учитываются
автопродления. Платежи, которые тренеры и репетиторы заносят внутри своих CRM,
не являются оплатой продукта и в этот поток не входят.

Чтение выполняется через существующий SSH-алиас `gmk-root`. Скрипт
`scripts/payment-snapshot.php` передаётся через stdin и выполняет только SELECT
в четырёх изолированных базах. Учётные данные баз остаются на сервере. Бот
отправляет сообщение только владельцу из `PAYMENT_ALERT_OWNER_ID` (или
единственному пользователю в `TELEGRAM_ALLOWED_USER_IDS`).

Для включения задайте `PAYMENT_ALERTS_ENABLED=true` в локальном `.env` и
перезапустите LaunchAgent. При первом запуске курсор сохраняется сразу, до
сетевого запроса: старые платежи не рассылаются, а новые не теряются при
временной недоступности SSH. После простоя Mac помощник дочитает накопившиеся
счета. Отправленные номера счетов и курсоры хранятся в
`ASSISTANT_DATA_DIR/payment-alerts.sqlite`; имена и суммы там не сохраняются.

Ссылки ведут в закрытые карточки ТВК и ГМК, кабинет «Тела в порядке» и
детализацию счёта «Где мои ученики». Для последней нужен
`platform_owner_telegram_id` в приватном production-конфиге ГМУ, привязанный
к аккаунту владельца. Без него ссылка закрыта.
