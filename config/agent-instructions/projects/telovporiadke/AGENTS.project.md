# Тело в порядке

`PLAN.md` owns the approved product direction. TVK, GMK and GMU are separate
products. Keep identities, accounts and histories isolated; the approved owner-only
support bridges use each product's own writer, with minimal recipient/chat data.

- Code, configuration, review, public copy, nutrition flows or private data: read
  [CODING_STANDARDS.md](CODING_STANDARDS.md), Product boundaries and Verification.
- Interface changes: read CODING_STANDARDS.md, Interfaces.
- Mobile builds, device testing/installation or store/test accounts: read
  CODING_STANDARDS.md, Mobile releases.
- «Выпусти приложение везде»: follow `docs/FULL-APP-RELEASE.md`; no separate
  «закрой» is required.
- «Кабинет» means the owner's specialist cabinet at
  `https://telovporyadke.ru/cabinet/`; its balance means Gemini balance in Overview
  unless Valentin or the context specifies another cabinet.

Existing paths in backticks resolve from this project's root. Global owner rules
govern browsers, presentation, memory and general closeout.
